# Moodboard review

## Direction A — Cherry Chrome Editorial

Strengths:

- most cinematic object rendering;
- strongest black/chrome material language;
- clear homes for phone, research, game, and book evidence.

Risks:

- can become a luxury-object gallery;
- repeated vertical panels could recreate V1's boxed rhythm;
- chrome cherries alone can read as a fashionable motif rather than Hasan's
  identity.

## Direction B — After-Hours Worktable

Strengths:

- most human and intimate;
- naturally accommodates handwriting, process, and physical artifacts;
- strong direction for the About page.

Risks:

- a staged desk scene is a familiar portfolio trope;
- many simultaneous objects weaken the one-idea rule;
- hard to sustain across research and software without becoming scrapbook-like.

## Direction C — Cut / Chrome / Signal

Strengths:

- type and hierarchy do the work before texture;
- most structurally ruthless;
- bold enough to feel young without relying on punk clichés;
- can absorb authentic evidence as precisely cropped “signals”;
- translates cleanly to a separately composed mobile layout.

Risks:

- needs excellent typography and exact spacing to avoid fashion-template
  anonymity;
- the identity object must become original to Hasan, not a generic pair of
  chrome cherries;
- cream-led pages need careful alternation so the whole site does not feel like
  a campaign deck.

## Recommendation

Advance **Direction C — Cut / Chrome / Signal**.

It is the only direction that remains premium when every decorative asset is
removed. Its punk energy comes from scale, interruption, and attitude. Its grid
can hold real evidence without turning the evidence into decoration.

Use the After-Hours lighting idea only as the dominant concept of the About
page; do not import its desk tableau into the global system. Use the cinematic
chrome quality demonstrated in Direction A when authoring Direction C's single
identity object; do not import A's panel wall.

This is not a three-way blend. Direction C remains the system.

## Hero-study review

The first desktop and mobile studies prove that the direction can pass the
ten-second test while still feeling unlike V1.

What works:

- the 3D object creates a memorable first read;
- black space and cream type feel controlled rather than empty;
- mobile is recomposed around a large identity statement and reachable actions;
- résumé and email remain visible without competing with the main action.

What must change before production:

- design an ownable identity object. The double cherry is the starting
  silhouette, not a final downloaded model;
- establish whether the hero leads with Hasan's name or the identity statement;
  the desktop and mobile studies currently prioritize them differently;
- verify the professional identity wording against the current résumé;
- replace generated typography and UI with actual accessible HTML;
- use the generated images as composition references only—never as flattened
  production pages;
- test the desktop statement at realistic browser sizes and make it more
  prominent if the ten-second read is weak;
- keep the mobile object shorter if it pushes the complete hero beyond a useful
  first-screen rhythm.
