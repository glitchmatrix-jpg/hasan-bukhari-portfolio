# Design-study generation record

These prompts produced exploratory reference images. The images are not
production UI, project evidence, or licensed third-party assets. Actual pages
must be built from accessible HTML, authored graphics, and approved evidence.

## Direction A — Cherry Chrome Editorial

```text
High-end landscape web art-direction moodboard for Hasan Bukhari's personal
portfolio. A disciplined 12-column editorial board with generous black negative
space and one commanding chrome double-cherry identity object. Supporting crops:
a floating black lyric-product phone, a red scientific validation plot on cream
paper, a moody pixel-game landscape escaping a dark frame, and a tactile cream
poetry book. Near-black, warm cream, deep cherry, polished silver; tiny muted
evidence accents. Luxury independent magazine art direction, photorealistic 3D,
restrained collage, subtle halftone and photocopy grain. One dominant focal
object; no cards, album/newspaper/department/game-menu metaphor, neon cyberpunk,
graffiti, excessive stickers, legible body copy, logos, trademarks, or watermark.
```

## Direction C — Cut / Chrome / Signal

```text
High-end landscape art-direction moodboard for a typography-led digital poster
system with selective cut-paper disruptions and chrome dimensional artifacts.
One enormous cropped editorial serif letterform and one small chrome cherry form
dominate. Supporting vertical signal slices: black phone silhouette, clean cream
research diagram, narrow pixel-game strip, embossed poetry page. Exactly three
physical interventions: stitched black patch, torn cream edge, translucent red
acetate. Warm cream, carbon black, deep cherry, chrome only. Extreme type scale,
museum-grade grid, bold but sparse. No ransom-note collage, graffiti, punk
clichés, generic cards, glossy cyberpunk, album/newspaper metaphor, readable
paragraphs, logos, trademarks, or watermark.
```

Output: `moodboards/direction-c-cut-chrome-signal.png`
