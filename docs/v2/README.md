# V2 design gate

V1 is preserved at tag `v0.9.0-v1-reference`. V2 work lives on
`design/living-portfolio-zine` until the visual direction passes review.

No production page composition should be rebuilt before the following gate is
approved:

1. creative thesis and anti-clutter rules;
2. source-of-truth content audit;
3. real-asset publication register;
4. licensed supporting-resource shortlist;
5. three moodboards and one chosen direction;
6. static desktop and mobile homepage compositions;
7. one software, one research, and one writing case-study prototype.

The V1 routes, semantic structure, accessibility behavior, content schemas,
tests, and deployment machinery remain infrastructure. V1's page compositions,
placeholder art, and decorative metaphors are not design constraints.
